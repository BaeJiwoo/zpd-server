서버와 클라이언트 기본 포트는 **20000**입니다. 서버를 실행한 뒤 클라이언트를 두 개 열어 `/enter`, `/create 2`, `/join <roomId>`, `/leave`를 사용할 수 있습니다. `/members`로 현재 참가자를 확인하고 `/quit`로 종료합니다.

최신 기준은 Markdown 문서입니다. `.docx`는 이전 참고용 사본이며 동기화하지 않았습니다. 코드 리뷰와 실제 실행 결과를 구분해 기록합니다. 커밋·푸시는 자동 실행하지 않습니다.

방에 들어간 뒤 일반 텍스트나 `/say 내용`을 입력하면 같은 방 전체에 전달됩니다. `/echo 내용`은 자신에게만 응답하는 테스트 명령입니다. 채팅 버전 실행·검증 기록은 작업 진행 기록 상단을 참고하세요.

전용 클라이언트는 `zpd-client.exe`입니다. 기존 `zpd-server-tests.exe <port>` 실행도 유지하지만 새 실행/디버그 설정은 전용 클라이언트를 사용합니다.

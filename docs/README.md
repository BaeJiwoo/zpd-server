## 시작 전에

- 현재 목표는 5단계 저장 상태를 확인하는 것입니다. 6단계는 사용자가 재개를 요청한 뒤 시작합니다.
- 코드 리뷰와 실행 검증은 별개입니다. 입장·중복 입장·재접속 통합 동작을 검증 완료로 취급하지 않습니다.
- 빌드·자동 테스트는 별도 요청 없이 실행하지 않습니다. 아래 문서의 확인 시나리오는 실행 계획입니다.
- 소스의 서버와 클라이언트 기본 포트는 모두 **9100**입니다. 기존 실행 파일은 소스와 다를 수 있으므로 실행 시 포트를 명시합니다.
- 편집기에 이전 내용이 남아 있으면 디스크 수정본을 덮어쓰지 않도록 비교합니다. 실제로 `PacketHandler.cpp`가 이전 이름으로 되돌아간 일이 있었습니다.

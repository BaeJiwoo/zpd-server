# 코드 스타일

`server/include/ZPDServer.hpp`를 기준으로 작성하며, 저장소 루트의 `.clang-format`을 적용합니다.

- 들여쓰기는 공백 4칸, 접근 지정자는 2칸으로 작성합니다.
- 타입과 함수 이름은 `PascalCase`로 작성합니다: `PacketHandler`, `OnConnected`.
- 매개변수, 지역 변수, 공개 데이터 필드는 `camelCase`로 작성합니다: `clientId`, `generation`.
- 클래스 내부 상태를 보관하는 멤버는 `m_camelCase`로 작성합니다: `m_packetHandler`.
- 상수는 `PascalCase`로 작성합니다: `MaxBufferSize`, `MaxEventQueueSize`.
- 헤더 가드는 `ZPD_파일명대문자_HPP` 형식으로 작성합니다.
- `main`, 표준 라이브러리, Windows API 및 Protobuf가 정의한 이름은 해당 규약을 따릅니다.
- 주석은 제약, 잠금 범위, 수명 및 코드만으로 드러나지 않는 이유를 설명합니다. 완료된 TODO와 주석 처리된 옛 코드는 남기지 않습니다.

프로젝트 C++ 파일과 프로토콜 정의에 서식을 적용하려면 clang-format이 설치된 환경에서 실행합니다.

```powershell
$sourceFiles = rg --files include src client tests proto -g '*.hpp' -g '*.cpp' -g '*.proto'
clang-format -i --style=file $sourceFiles
```

생성된 Protobuf 코드와 외부 의존성에는 적용하지 않습니다. clang-format은 서식을 정리하며, 이름 변경은 선언과 사용 위치를 함께 수정해야 합니다.

- 통신 한도는 `ProtocolLimits.hpp`, 네트워크 기본값은 `NetworkSettings.hpp`, 서버 큐 한도는 `ServerLimits.hpp`, 클라이언트 설정은 `mockclient/include/ClientSettings.hpp`에 둡니다. 같은 숫자를 서로 다른 정책에 재사용하지 않습니다.
- 데이터 구조에는 해당 데이터만 두며 Windows I/O, 패킷, 게임 세션을 한 헤더에 섞지 않습니다.
- 헤더에는 공개 계약과 멤버 선언을, 구현 파일에는 처리 흐름을 둡니다. 템플릿과 작은 값 타입의 직렬화 함수는 필요에 따라 헤더에 둡니다.
- 연결 슬롯은 `slotIndex`, 플레이어 식별자는 `playerId`, 방 식별자는 `roomId`로 구분합니다.
